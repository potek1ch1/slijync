# プレゼン同期アプリ 仕様書

> ステータス: Draft  
> 最終更新: 2026-11-19
> 決定済みの仕様、仮の用語、今後決める事項を管理するための文書。

## 1. 概要

スライド資料を個別に閲覧したり、セッションに参加して複数人で同じスライドを同期表示したりできるアプリ。

## 2. 決定事項

### 2.1 閲覧モード

スライドショーには、次の2つのモードがある。

#### 通常閲覧モード（仮称）

- ユーザーが個別にスライド資料を閲覧する。
- ページの移動は他のユーザーに影響しない。
- 他のユーザーのページ移動にも影響されない。

#### セッションモード（仮称）

- ユーザーが特定のセッションに参加して閲覧する。
- 同じセッションの参加者全員で現在のページを共有する。
- Operatorがページを移動すると、同じセッションの全員に反映される。

### 2.2 権限

権限はセッションではなく、スライド資料に対して設定する。

スライド資料に対して、OwnerとOperatorを明示的に管理する。それ以外のユーザーはViewerとして扱う。

#### Owner（仮称）

- Operatorの権限をすべて含む。
- 対象スライド資料のタイトルを変更できる。
- 対象スライド資料のPDFを差し替えられる。
- 対象スライド資料を削除できる。
- 対象スライド資料のOwnerとOperatorを追加・削除できる。

#### Operator（仮称）

- 対象スライド資料のセッションを作成・終了・再開できる。
- 対象スライド資料のセッションで、現在スライドを移動できる。
- セッション外のスライド資料管理はできない。

#### Viewer（仮称）

- 対象スライド資料を閲覧できる。
- 対象スライド資料のセッションで、現在スライドを移動できない。

権限による操作制限は、画面上で操作ボタンを隠すだけでなく、サーバー側でも検証する。

### 2.3 セッションの開始とOperatorの追加

- ユーザーがスライド資料からプレゼンを開始するとき、閲覧方法を選択できる。
- 選択肢は「通常閲覧モード」と「セッションモード」とする。
- 所有者またはOperatorがセッションモードを選択すると、新しいセッションを作成する。
- セッション作成時に、セッション専用のURLを発行する。
- セッションを作成した所有者またはOperatorが、発行されたURLを他のユーザーに共有する。
- URLを知っているユーザーは、誰でもそのセッションにViewerとして参加できる。
- 初期リリースでは、参加コード、入室承認、参加者登録は設けない。
- 所有者が、他のユーザーをそのスライド資料のOperatorとして追加・削除する。
- スライド資料のOperatorは、そのスライド資料から作成されたセッションでスライドを操作できる。
- Operatorはメールアドレスを指定して追加する。

### 2.4 同期範囲

- 同期の単位はセッションとする。
- 同じセッションに参加している人は、同じ現在ページを表示する。
- 別セッションや通常閲覧モードのユーザーには影響しない。

### 2.5 閲覧範囲

- 初期リリースでは、スライド資料の閲覧にアカウントを要求しない。
- スライド資料は、URLなどの閲覧手段を知っている全員が閲覧できる。
- 初期リリースでは、スライド資料ごとの公開範囲設定や閲覧者制限は設けない。
- 閲覧できることと、セッション内でスライドを操作できることは別に扱う。
- Viewerの氏名、アカウント、参加履歴などの参加者情報は取得・管理しない。

### 2.6 認証

- 所有者とOperatorは認証を必須とする。
- 認証方式にはOIDC（OpenID Connect）を使用する。
- OIDCで識別されたユーザーに対して、スライド資料ごとの所有者・Operator権限を紐づける。
- Viewerは認証不要とし、セッション専用URLから匿名で参加できる。
- 初期リリースではGoogleのみをOIDCプロバイダーとして使用する。
- 将来、Google以外のOIDCプロバイダーや自前IdPにも対応できる構成とする。
- 所有者がOperatorを追加するときは、メールアドレスでユーザーを指定する。
- まだ一度も認証しておらず、システムに登録されていないメールアドレスはOperatorまたはOwnerに指定できない。
- アプリ内部のUserと、OIDCプロバイダー上のIdentityを分けて管理する。
- OIDC Identityは、発行者を示す `iss` とプロバイダー内ユーザー識別子 `sub` の組み合わせで一意に識別する。
- Owner・Operator権限はOIDC Identityではなく、アプリ内部のUserに紐づける。
- Userは検証済みメールアドレスを保持し、メールアドレスによる権限付与対象の検索に使用する。
- メールアドレスはログインユーザーを恒久的に識別する主キーとして使用しない。

### 2.7 スライド資料の登録と管理

- 認証済みユーザーがPDFをアップロードしてスライド資料を登録する。
- PDFをアップロードしたユーザーを、そのスライド資料の最初の所有者とする。
- 登録時にスライド資料のタイトルを入力する。
- Ownerは登録済みPDFを差し替えられる。
- Ownerはスライド資料のタイトルを変更できる。
- Ownerはスライド資料を削除できる。
- OperatorとViewerは、PDFの差し替え、タイトル変更、スライド資料の削除を実行できない。
- 初期リリースでは、削除したスライド資料を復元する機能を提供しない。
- スライド資料を削除した場合、関連するセッションを終了する。
- 削除されたスライド資料に関連するURLへアクセスした場合、削除済みであることを表示する。
- セッション開始時に、その時点のPDF版をセッションへ固定する。
- 開催中にPDFが差し替えられても、そのセッションには反映しない。
- 差し替え後のPDFは、次回セッションを開始または再開した時点から反映する。

### 2.8 セッションのライフサイクル

- セッションは「開始前」「開催中」「終了」の状態を持つ。
- セッション専用URLは、セッション開始前からアクセスできる。
- 開始前にアクセスしたViewerには、セッションがまだ開始されていないことを示す待機画面を表示する。
- 所有者またはOperatorがセッションを開始したとき、待機中のViewerを自動的に現在スライドへ遷移させる。
- 所有者またはOperatorがセッションを終了できる。
- セッション終了中もセッション専用URLは保持する。
- 終了後にアクセスしたViewerには、セッションが終了したことを示す画面を表示する。
- 同じセッションを再開した場合、既存のセッション専用URLを再び有効にする。
- セッションを再開したとき、URLを開いて待機しているViewerを自動的に現在スライドへ遷移させる。
- セッションを開始または再開するときは、常に1枚目のスライドから開始する。
- 1つのスライド資料に対して、複数のセッションを同時に開催できる。
- 各セッションは、専用URL、状態、現在スライドを独立して保持する。
- セッション開始時に30分の無操作タイマーを開始する。
- Operatorによるスライドの「前へ」「次へ」が行われるたびに、無操作タイマーを30分へ戻す。
- Operatorによる操作が30分間行われなかった場合、セッションを自動的に終了する。
- Viewerによる閲覧や接続は、無操作時間をリセットしない。

### 2.9 同時操作と接続復旧

- 複数のOperatorが同じセッションを操作できる。
- 複数の操作が競合した場合、最後にサーバーへ届いた操作を採用する。
- Viewerが途中参加した場合、セッションの現在スライドを表示する。
- 切断後に再接続した場合、セッションの現在スライドへ復旧する。
- Operatorが切断してもセッションを継続する。

### 2.10 スライド操作とURL

- 初期リリースのスライド操作は「前へ」と「次へ」を提供する。
- URLからスライド資料へアクセスできる。
- URLで特定のスライドを指定して開けるようにする。

## 3. 仮の用語

| 用語 | 意味 | 状態 |
|---|---|---|
| スライド資料 | 閲覧対象となる資料全体 | 仮称 |
| 通常閲覧モード | 個別に閲覧するモード | 仮称 |
| セッションモード | 複数人で同期して閲覧するモード | 仮称 |
| セッション | 同じ現在ページを共有する単位 | 仮称 |
| Owner | Operator権限を含み、スライド資料と権限を管理できるユーザー | 仮称 |
| Operator | スライド資料のセッションでスライドを操作できるユーザー | 仮称 |
| Viewer | OwnerでもOperatorでもなく、スライド資料を閲覧するユーザー | 仮称 |
| スライド | スライド資料内の1ページ | 仮称 |
| 参加者 | セッションに接続しているユーザー | 仮称 |

## 4. 機能要件

### FR-001: 通常閲覧

システムは、ユーザーがセッションに参加せずプレゼンテーションを閲覧できるようにする。

### FR-001-1: プレゼン開始時のモード選択

システムは、ユーザーがスライド資料からプレゼンを開始するとき、通常閲覧モードまたはセッションモードを選択できるようにする。

通常閲覧モードを選択した場合は個別にプレゼンを開始し、セッションモードを選択した場合は新しいセッションを作成してプレゼンを開始する。

### FR-002: セッション作成

システムは、スライド資料の所有者またはOperatorがセッションを作成できるようにする。

### FR-003: セッション参加

システムは、ユーザーがセッション専用URLにアクセスすることで、誰でも既存のセッションにViewerとして参加できるようにする。

### FR-004: 現在ページの同期

各セッションは現在ページを1つ保持し、現在ページが変更されたとき、同じセッションの参加者全員へ反映する。

### FR-005: Operatorによる操作

Operatorは、セッションの現在ページを変更できる。

### FR-005-1: Operator管理

所有者は、スライド資料に対するOperatorを追加・削除できる。

### FR-005-2: 所有者管理

所有者は、スライド資料に対する所有者を追加・削除できる。

- 所有者は複数人設定できる。
- 最後の1人の所有者は削除できない。
- 所有者は自分自身を削除できない。

OwnerはOperatorの権限をすべて含む。

### FR-006: Viewerの操作禁止

Viewerは、セッションの現在ページを変更できない。

### FR-007: セッション間の分離

あるセッションでのページ変更は、別のセッションや通常閲覧モードの表示を変更してはならない。

### FR-008: アカウントなしの閲覧

システムは、Viewerがアカウントを作成せずにスライド資料を閲覧できるようにする。

### FR-009: 閲覧制限なし

初期リリースでは、スライド資料の公開範囲や閲覧者を限定する機能を提供しない。

### FR-010: Viewer情報の非管理

システムは、Viewerを個別の参加者として登録・管理せず、匿名の閲覧者として扱う。

### FR-011: セッションURLの発行

システムは、所有者またはOperatorがセッションを作成したとき、そのセッション専用のURLを発行する。

所有者またはOperatorはそのURLを他のユーザーに共有できる。URLを知っているユーザーは、追加の参加者登録なしでセッションを閲覧できる。

### FR-012: OIDC認証

システムは、OIDCを使用して所有者とOperatorを認証する。

認証済みユーザーの識別子を、スライド資料ごとの所有者・Operator権限に紐づける。Viewerによる閲覧およびセッション参加には認証を要求しない。

初期リリースではGoogleによるOIDC認証に対応する。所有者は、メールアドレスを指定してOperatorを追加できる。

システムに登録されていないメールアドレスは、OperatorまたはOwnerに指定できない。

システムはアプリ内部のUserとOIDC Identityを分離して管理する。OIDC Identityは `iss` と `sub` の組み合わせで識別し、Owner・Operator権限は内部Userに紐づける。

### FR-013: スライド資料の登録

システムは、認証済みユーザーがPDFとタイトルを指定してスライド資料を登録できるようにする。登録したユーザーを、そのスライド資料の最初の所有者とする。

### FR-014: PDFの差し替えと削除

システムは、Ownerに対して、タイトル変更、登録済みPDFの差し替え、スライド資料の削除を提供する。OperatorとViewerにはこれらの操作を許可しない。

初期リリースでは削除したスライド資料を復元できない。スライド資料を削除した場合は関連セッションを終了し、関連URLでは削除済みであることを表示する。

開催中のセッションは、開始時点のPDF版を使用し続ける。PDFの差し替えは開催中のセッションには反映せず、次回の開始または再開から反映する。

### FR-015: セッションの終了と再開

所有者またはOperatorはセッションを終了・再開できる。終了したセッションを再開した場合、既存のセッション専用URLを再び有効にする。

セッションを開始または再開するときは、常に1枚目のスライドから開始する。

### FR-015-1: 開始前・終了後の待機画面

セッション専用URLはセッション開始前からアクセス可能とする。開始前は未開始を示す待機画面、終了後は終了を示す画面を表示する。

セッションが開始または再開された場合、URLを開いて待機しているViewerを現在スライドへ自動的に遷移させる。

### FR-016: セッションの自動終了

システムは、セッション開始時に30分の無操作タイマーを開始する。Operatorが「前へ」または「次へ」を操作するたびにタイマーを30分へ戻し、操作が30分間なければセッションを自動的に終了する。Viewerの閲覧や接続では無操作時間をリセットしない。

### FR-016-1: 複数セッション

1つのスライド資料に対して複数のセッションを同時に開催できる。各セッションは、専用URL、状態、現在スライドを独立して保持する。

### FR-017: 複数Operatorと競合

複数のOperatorが同じセッションを操作できる。操作が競合した場合、最後にサーバーへ届いた操作を採用する。

### FR-018: 途中参加と再接続

途中参加または再接続したユーザーには、セッションの現在スライドを表示する。Operatorが切断してもセッションを継続する。

### FR-019: 基本操作とスライドURL

初期リリースでは「前へ」と「次へ」の操作を提供する。また、URLでスライド資料および特定のスライドへアクセスできるようにする。
